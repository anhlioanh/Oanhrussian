# OanhRussian 🇷🇺

Website học tiếng Nga hiện đại, trực quan và tối ưu cho người Việt.

## 🛠 Tech Stack
- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS, shadcn/ui
- **Database & Auth:** Supabase (PostgreSQL)
- **Deployment:** Vercel
